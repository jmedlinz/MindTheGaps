# MindTheGaps

### MindTheGaps

Powershell scripts that analyze a folder of time-based screenshots (for example, TimeSnapper) to report work timespans and total hours worked.

This script was designed to work with folders like those created by the [TimeSnapper](http://www.timesnapper.com/) software application. Timesnapper creates a new folder each day, and as you work it stores screenshots every few seconds. This is useful for tracking what you worked on and when throughout your work day.

Although the tools and reporting from Timesnapper are excellent, manually analyzing the output into a summary for notes each day was time consuming. This script was created to automate it.

Example usage:
```powershell
# Show the times worked and gaps for 3 days ago:
.\mindthegaps.ps1 -3
```

Example of output:

![Example output of MindTheGaps](./mtg_example.png?raw=true "Example output of MindTheGaps")

By default the script will show gaps between the work sessions. This can be useful to track how long you're taking on breaks and other non-work activities.

#### Parameters

- `-DaysBack`: Number of days back to process. `-1` means yesterday, `-7` means a week ago. Positive values are normalized to their absolute value.
- `-ShowGaps`: Shows the gaps between work periods in the output. By default this is enabled for the main script and disabled for the weekly summary.
- `-SkipDuplicates`: Examines files for duplicate images before calculating work. When enabled, duplicate files are ignored during analysis so only the first copy in the folder contributes to the work totals. This is slower than the default behavior.

  > Beta feature warning: `-SkipDuplicates` is considered beta-quality. It can be inconsistent depending on image quality, and results should not be trusted.

### WeeklyGaps
Runs the *MindTheGaps* script for each day of the week and summarizes the results. This script will also show the total hours worked for the week.
By default, gaps are not shown in the weekly summary. This can be changed with the `-ShowGaps` switch.

Example usage:
```powershell
# Show the weekly report, including gaps, for last week:
.\weeklygaps.ps1 -1 -ShowGaps
```

#### Parameters

- `-WeeksBack`: Number of weeks back to process. `-1` means last week; positive values are normalized to their absolute value.
- `-ShowGaps`: Includes the gaps between work periods in the weekly summary.
- `-SkipDuplicates`: Same duplicate-image filtering behavior as the daily script.

  > Beta feature warning: `-SkipDuplicates` is considered beta-quality. It can be inconsistent depending on image quality, and results should not be trusted.

### FillTheGap
There are times when no files are generated by the time-tracking software but you may still be working, such as during meetings, reading, phone calls, etc. Instead of manually accounting for those times outside of *MindTheGaps*, an additional script can fill in those gaps. The *FillTheGap* script creates dummy files that are usable by *MindTheGaps* but not by TimeSnapper itself.

Example usage:
```powershell
# Fill a gap from 10:15am to 10:30am for two days ago:
.\fillthegap.ps1 10:15am 10:30am -2
```

#### Parameters

- `StartTime`: The beginning of the time range to fill. Supported examples include `9:30am`, `9:00pm`, `8pm`, `12am`, `8:01a`, `5:55p`, `8a`, and `5p`.
- `StopTime`: The end of the time range to fill. Uses the same accepted formats as `StartTime`.
- `-DaysBack`: Number of days back to place the created files in. `-1` means yesterday; positive values are normalized to their absolute value.

### ClearTheGap
Sometimes you may use personal time, such as lunch, for browsing or other activities that you do not want to count toward TimeTracker or *MindTheGaps*. *ClearTheGap* will rename a block of image files so they are ignored by the analysis logic.

Example usage:
```powershell
# Clear the gap from 12:00pm to 1:00pm today:
.\clearthegap.ps1 12:00pm 1:00pm
```

#### Parameters

- `StartTime`: The beginning of the time range to clear. Supported examples include `9:30am`, `9:00pm`, `8pm`, `12am`, `8:01a`, `5:55p`, `8a`, and `5p`.
- `StopTime`: The end of the time range to clear. Uses the same accepted formats as `StartTime`.
- `-DaysBack`: Number of days back to clear files from. `-1` means yesterday; positive values are normalized to their absolute value.

### Configuration and behavior notes

Several thresholds and paths are defined in the script configuration and affect how the analysis behaves:

- `BreakLimit`: Number of minutes of inactivity before a work session is treated as a break or gap. Default is `15` minutes.
- `WorkLimit`: Minimum duration required for a block of files to count as work. Default is `3` minutes.
- `SnapshotFolder`: The root folder containing the TimeSnapper image snapshots. Default is `D:\SnapShots\`.
- `ArchivePostfix`: The suffix added to archived snapshot folders. Default is `.archive`.
- `KeepFilesDays`: Number of days worth of archive data to retain before orphaned archive folders are removed. Default is `45` days.
- `FileExt_Fill`: The file extension used for generated gap-filling images. Default is `jpg`.
- `FillFilePrefix`: Prefix used for generated files. Default is `filled-`.
- `ClearFilePrefix`: Prefix used for cleared files. Default is `cleared-`.

The daily analysis reads both the current day's snapshot folder and its archive folder, filters for supported image types, ignores folders, and excludes files that were intentionally created as filled or cleared markers. It also cleans up orphaned archive folders when the corresponding daily folder no longer exists.
